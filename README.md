This is my 2D Unity game project

I wanted to create a 2D game with a similar playstyle to the classic game "Plants vs. Zombies". The current build of the game has two enemy types and two ally types that you can see when playing.  It also only has an endless mode which can be accessed when starting the game.

Changes that I have made compared to my original proposal is level design.  In my proposal, I wanted to create multiple levels that unlock new characters, enemies, and progressively gets harder.  With the timeframe that I gave myself, I stuck with just creating one endless mode that progressively gets more and more difficult, the more more you play.  I also wanted to add a lot more characters and enemies that you could use but decided to focus more on the base mechanics of the game, how the game runs, controls, and feels.  If I were to spend more time outside of the project's due date, I would add more characters, enemies, enemy types such as summoners, healers, grunts, and I would add a level design system which would be controlled by level data. 

Overall I am happy with how it turned out and personally love the design and sounds of the game.  I will definilty be working on this game outside of this project to make feel more polished and fun.

Go into game builds --> Cane vs. The Undead --> and run myproject.exe
